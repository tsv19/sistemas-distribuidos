Registro de desenvolvimento

Nos dias 21 e 24 de julho os alunos Tiago Serique e Vinícius M. Ribeiro se reuniram para discutir a respeito do trabalho prático 2 da disciplina de Sistemas Distribuídos. O trabalho consiste em implementar um algoritmo de árvore geradora mínima autonômica sobre o VCube na versão 2. O trabalho prático 2 é uma continuação do trabalho prático 1, que serviu como base para a execução. Você pode acessar o trabalho prático 1 neste link

Para melhor organização, dividimos o trabalho em 3 pequenas tarefas, sendo elas:

  1. Implementação do algoritmo de árvore geradora mínima autonômica (algoritmo abaixo);
  2. Adaptação do trabalho prático 1 para executar o algoritmo de árvore geradora mínima autonômica;
  3. Execução do algoritmo em diferentes cenários e coleta de logs;

Tarefa 1

A tarefa 1 consiste em implementar o algoritmo de árvore geradora mínima autonômica, antes de integrá-lo ao VCube. O algoritmo é descrito abaixo:

Algoritmo Árvore Geradora Mínima Autonômica sobre o vCube

        Recebe como entrada: Raiz da árvore, Dimensão do vCube, Lista de processos falhos

        Imprima(raiz)

        Seja i o primeiro processo correto de C(raiz, s-filho), s-filho = 1, 2, ..., 
        Dimensão do vCube (se houver algum): Imprima(i)

        A raiz envia o s-filho correspondente para cada filho i

        Se i recebe s-filho = 1
        Então esse filho é folha, acabou!
        Senão /* s-filho > 1 */
            o filho i envia s para o primeiro processo j correto de C(filho,s), s = 1, 2, ..., s-filho -1 
            (se houver algum): Imprima(j)

        Repita para cada um dos filhos, até todos serem folhas e acabarem a execução do algoritmo. 
        Fim Algoritmo.

Na implementação realizada do algoritmo, foi utilizada uma lista de onde cada elemento é um processo e, a partir da raiz, adicionamos os filhos na lista na mesma ordem que os s-filhos são enviados, assim garantimos que o log da árvore segue a mesma ordem que uma BFS.

Primeiro garantimos que a árvore está sendo devidamente montada, e após isso, adaptamos para que funcione com o VCube.

Tarefa 2

Durante a tarefa 2, adaptamos o algoritmo do trabalho prático 1 para que a árvore geradora mínima autonômica fosse gerada a partir do VCube.

Para isso, da mesma forma que no trabalho 1, foi necessário configurar os processos que deveriam falhar para cada log obtido na mão antes da execução. Durante a execução, o simulador realiza o mesmo comportamento do trabalho anterior, porém, com saídas de log mais simples, apenas com conteúdo necessário para entender quem testou e o vetor de estado.

Após a execução do VCube for completa e todos os processos conhecerem o estado de todos os outros, o simulador recebe um evento novo chamado "generate", que é responsável por gerar a árvore geradora mínima autonômica a partir dos processos da simulação.

Tarefa 3

Os logs gerados neste trabalho comtemplam os seguintes cenários:

  1. Raiz: 0 - Dimensões do vCube: 2 - nenhum processo falho
  2. Raiz: 0 - Dimensões do vCube: 3 - nenhum processo falho
  3. Raiz: 0 - Dimensões do vCube: 3 - Lista de processos falhos: 1, 2, 4, 7
  4. Raiz: 7 - Dimensões do vCube: 3 - Lista de processos falhos: 0
  5. Raiz: 0 - Dimensões do vCube: 4 - nenhum processo falho
Cada log contém a saída do algoritmo VCube, onde cada processo diz ser o testador em um determinado tempo e o seu vetor de estado, e também a saída do algoritmo de árvore geradora mínima autonômica.
